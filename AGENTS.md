# Project Guidelines

## Stack

- Craft CMS 5
- Twig
- Tailwind CSS
- Alpine.js
- Google Maps plugin
- Formie plugin

## Development

- Run project commands through DDEV when needed.
- Prefer `ddev composer update` over running Composer directly.
- Prefer `ddev craft ...` for Craft CLI commands.
- Prefer `ddev npm ...` for frontend tooling when Node runs in DDEV.

## Approach

- Keep solutions simple and direct.
- Prefer native Craft, Twig, Alpine.js, and Tailwind features over extra abstractions or dependencies.
- Use inline native Tailwind utility classes when possible.
- Avoid unnecessary variables, helper functions, components, and configuration.
- Keep comments useful and concise.

## Communication

- Use a casual, concise tone.
